# ISCAS-85 BENCH Veri Kümesi

Bu klasördeki `c17`, `c880`, `c1355`, `c1908`, `c2670`, `c3540`, `c5315`, `c6288` ve `c7552` BENCH dosyaları Tallinn Teknik Üniversitesi benchmark arşivinden alınmıştır:

`https://pld.ttu.ee/~maksim/benchmarks/iscas85/bench/`

Bu sürümler SHIELD makalesinde verilen standart primary-input sayılarına uyar. `legacy/c880.bench`, özgün Python kodunun node adlarını `int` tipine çevirebilmesi için aynı c880 dosyasından yalnız `G` önekleri kaldırılarak üretilmiştir.
